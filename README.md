# 🌸 Nordic Bloom – Flower Webshop

Nordic Bloom is a flower webshop developed as part of our 3rd semester Multimedia Design CMS exam project. The website allows customers to browse flower categories, view individual products, add items to their cart, and complete purchases through WooCommerce. It also features a Flower Club subscription page, a blog with individual articles and comments, a sustainability page, and a contact form with validation.

The project combines custom WordPress theme development with PHP, Advanced Custom Fields (ACF), HTML, CSS, and JavaScript to create a flexible and maintainable website.

**🌐 Live Website:** [https://flowerswebshop.dk/]
## 🛠️ Technologies Used

- **WordPress** – Content management system
- **PHP** – Custom theme development and dynamic content
- **Advanced Custom Fields (ACF)** – Dynamic content management
- **HTML5** – Semantic structure
- **CSS3** – Responsive layouts and styling
- **JavaScript** – Interactive functionality

## 📐 Design & Development Process

The project followed a structured process, beginning with research and planning, including an ORCA analysis and user personas.

The design focused on a minimal and elegant visual identity, using soft colors, balanced spacing, and clear typography.

Development involved creating a custom WordPress theme with reusable PHP templates and dynamic content management through ACF.

Throughout the project, the website was reviewed and improved for responsiveness, accessibility, usability, and functionality.
